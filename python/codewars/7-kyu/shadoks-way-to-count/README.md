<h2><a href=https://www.codewars.com/kata/6b00d45ad1103df1762bded3/train/python target="_blank">Shadok's way to count</a></h2><h3>7 kyu</h3><p>In this kata you have to make a function <code>shadok(n)</code> that takes a positive or zero integer <code>n</code> and return it in "Shadok".</p><p>You don't know what Shadoks are? I think not... You should. If you want to know more you can take a look on the <a href="https://en.wikipedia.org/wiki/Les_Shadoks" data-turbolinks="false" target="_blank">Shadok's wikipedia</a>. (you will like it for sure)</p><p>For this kata you only need to know that they are counting.... in a really special way. Because of their brain that have four cells they only know the four syllables "GA", "BU", "ZO" and "MEU" (read : [mø]).</p><h2 id="rules">Rules</h2><ul><li>"GA" means 0 item.</li><li>"BU" means 1 item.</li><li>"ZO" means 2 items.</li><li>"MEU" means 3 items.</li><li>After that they repeat this by putting four items in a little bin. And they count these bins with the same syllables.</li><li>When they have 4 four little bins they put them in a bigger little bins... And count them with same syllables...</li><li>When they have four of these bigger little bins they put them in a normal bin... And repeating the same thing.</li><li>And repeating this with always bigger bins. Yeah, it's a bit of pain.</li><li>Like us they place the syllable of the bigger bin before the other. (ex: 10, 1 is equivalent to the syllable of the bigger bin but we say that it is the ten and not a "little bin").</li></ul><h2 id="examples">Examples</h2><pre><code class="language-python"><span class="cm-variable">shadok</span>(<span class="cm-number">7</span>)     <span class="cm-operator">=&gt;</span>   <span class="cm-string">"BUMEU"</span><span class="cm-variable">shadok</span>(<span class="cm-number">33</span>)    <span class="cm-operator">=&gt;</span>   <span class="cm-string">"ZOGABU"</span> <span class="cm-variable">shadok</span>(<span class="cm-number">356</span>)   <span class="cm-operator">=&gt;</span>   <span class="cm-string">"BUBUZOBUGA"</span></code></pre><p>Good luck, I hope that you will have fun with my first kata &lt;3.</p>
